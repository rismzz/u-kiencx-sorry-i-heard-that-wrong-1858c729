Sorry, I Heard That Wrong — the funniest one-line apology a smart speaker gives after mishearing its owner. A model judges entries two at a time on humour and freshness.

> Sorry — I heard 'play jazz' as 'order twelve pizzas,' and honestly, the pizzas are already at the door, so who's the real smart one here?

## Run it

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: no network, no randomness, no model calls — the same line every run.
